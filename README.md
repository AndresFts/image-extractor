Simple CLI to read a .csv or .ods (exact headers: Channel, URL) and download
logo images from each webpage by selecting the img element with both classes:
  imageWithDefault-module__image___l4XCi profile-logo-module__logoImage___pjwzX

Usage:
  ./image-extractor /path/to/list.csv
  ./image-extractor /path/to/list.ods

Install requirements (simple):
  pip install -r requirements.txt
